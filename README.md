# Proyecto Final — Clasificación de Texto

Este proyecto implementa un sistema completo de clasificación de texto, desde el preprocesamiento hasta la evaluación de modelos. El objetivo es analizar un conjunto de datos, limpiarlo, transformarlo en representaciones numéricas y entrenar diferentes algoritmos de machine learning para comparar su desempeño.  
El repositorio incluye notebooks exploratorios, código modular para procesar datos, extraer características, entrenar modelos y almacenar artefactos generados durante el proceso.

El flujo general del proyecto considera:

- Análisis exploratorio del dataset.
- Preprocesamiento de texto (limpieza, normalización y transformación).
- Extracción de características mediante TF-IDF y/o embeddings.
- Entrenamiento de modelos clásicos de clasificación.
- Obtención y comparación de métricas de desempeño.
- Almacenamiento de artefactos (modelos y preprocesadores).
- Organización del código en módulos para facilitar experimentación y mantenimiento.
